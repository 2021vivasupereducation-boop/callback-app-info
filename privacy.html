Privacy policy
隐私政策

适用应用：Classroom Report Archive Bot，包括其经启用的 Callback 工作流。本政策描述数据用途，不代表所有集成功能已完成部署。

1. 处理哪些资料 / Data processed

经操作者主动提供的录音、视频、姓名、年级、通话日期、文字说明、转写、审阅记录和处理状态。Google 集成可能处理已授权账号的邮箱、指定文件夹和文件的标识、权限、存储配额以及上传核验信息。访问与刷新令牌用于维持已获同意的访问，不应提交到聊天或公开网站。

2. 为什么使用 / Purpose and access

资料仅用于操作者明确请求的教学记录整理、私人归档、审阅和经批准的记录更新。当前 Drive 集成通过广泛的 Drive OAuth scope 授权，并在应用中限制目标文件夹；操作者应根据授权页面决定是否同意。Google Sheets 或其他集成需要另外配置，不因本次 Drive 授权自动获准。

3. 服务提供方与 AI / Providers and AI processing

启用的工作流可能使用 Telegram 收件、Google Drive 存储，以及配置的语音转写或 AI 服务。只有在所需功能、预算、资料处理权限和相关服务条款均获确认后，才应启用相应处理。服务提供方适用自己的条款、留存及处理政策；本应用不承诺服务方零留存。

This application's use and transfer of information received from Google APIs must adhere to the Google API Services User Data Policy, including its Limited Use requirements. The application does not sell Google user data, use it for advertising, or use it to develop or train generalized AI/ML models. Do not enable a processing provider whose applicable terms or settings would violate these requirements.

4. 保存与安全 / Storage and security

归档目标为操作者指定、经核对的私人文件夹。处理过程可能需要临时本地或云端副本，以及用于恢复和核验的状态记录。当前 Windows 授权使用当前用户 DPAPI 加密；这不等同于所有媒体端到端加密或未来云端存储已配置。未完成的任务可能保留必要的恢复资料。没有统一的固定自动删除期限，不承诺归档后立即删除所有临时副本。

5. 控制、撤销与删除 / Your choices

操作者可停止提交资料、在 Google 账号安全设置中撤销应用访问，并自行管理其 Drive 文件。撤销授权不会自动删除已保存的 Drive 文件、Telegram 消息、教学 PDF 或表格记录。联系下方支持邮箱可请求核查应用持有的资料与删除范围；需核实请求者权限并保留必要的法定记录。不要在公开 GitHub issue 或邮件中附上通话原件、密码或令牌。

6. 本说明网站 / This information website

此静态网站不包含学生资料、录音、OAuth 凭据或私人 Drive 链接，不设置媒体上传表单、追踪脚本或广告。托管服务方可能按其自身政策处理网络访问日志。本网站无 cookie 分析脚本并不代表托管商不处理访问元数据。

7. 联系与变更 / Contact and changes

运营与隐私联系：wlwswilson1128@gmail.com。处理方式发生变化时应更新本政策，并在需要时重新取得授权或同意。
